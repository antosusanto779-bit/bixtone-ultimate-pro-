## 🚀 Tentang Proyek
**BIXTONE ULTIMATE PRO** adalah aplikasi web studio musik berbasis kecerdasan buatan (*AI Music Generator*) yang dirancang khusus untuk para kreator, musisi, dan produser. Aplikasi ini memungkinkan pengguna untuk menghasilkan trek musik, ketukan drum (*drum beats*), dan aransemen instrumen profesional secara instan hanya melalui perintah teks (*prompt-to-audio*).

Dibuat dengan pendekatan *mobile-first workflow*, aplikasi ini dioptimalkan agar dapat dikembangkan, dikustomisasi, dan dijalankan langsung dari perangkat seluler menggunakan ekosistem *cloud* terbuka.

---

## ✨ Fitur Utama
* **L1 - Vocal & Concept Prompt:** Tulis deskripsi lagu, genre, atau struktur ritme kustom Anda sendiri.
* **L2 - Micro-Presets & Instrumentation:** Akses cepat ke preset gaya musik populer (Rock/Metal, Electronic, Lo-Fi Chill, Cinematic).
* **L3 - Studio Mastering & BPM Control:** Pengaturan tempo (*BPM Selector*) dan parameter mixing untuk hasil audio berkualitas tinggi.
* **Cloud AI Engine Integration:** Terhubung langsung ke mesin *Generative Audio* berkecepatan tinggi di *cloud* secara gratis dan tanpa batas platform.
* **Dark Studio Aesthetic:** Antarmuka modern dengan kombinasi warna gelap, biru neon, perak, dan aksen emas ala studio rekaman profesional.
