## 🌟 Fitur Utama
- **Desain UI Mewah:** Gradasi Biru Tua, Biru Muda, Silver Tua, Silver Muda, dan Kuning Emas dengan Logo Vektor Eksklusif BIXTONE.
- **Dual Mode:** 
  - **Mode Lite / Standar:** Fokus pada Vokal, Karakter Vokal, Mood, Efek Vokal, dan Genre Musik.
  - **Mode Expert / Pro:** Membuka seluruh 1.420+ katalog perangkat keras, instrumen dunia, 3-Layer Prompt Engine, dan Studio Workstation.
- **Bilingual (ID / EN):** Mendukung Bahasa Indonesia dan Bahasa Inggris secara instan.
- **Arsitektur 3-Layer Prompt Engine:**
  - **Layer 1 (Vocal Layer):** Tipe vokal (Male/Female/Duet), Karakter Vokal (max 8), Efek Vokal (1), dan Lirik Manual.
  - **Layer 2 (Instrument Layer):** Mood (max 8), Genre (max 8), Mic (1), Amp (max 4 Series/Parallel), Gitar 1 & 2 (Elektrik/Akustik terpisah), Bass (1 dari 500 brand), Snare (1), Cymbals (1), Alat Musik Dunia (max 8), Efek Gitar (max 12), Efek Bass (max 10), Durasi (1-8 Menit), Tempo (50-200 BPM), dan **Prioritas Struktur Melodi (Intro - Bridge/Solo Tengah - Outro)**.
  - **Layer 3 (Studio Mixing & Mastering):** Konsol Mixer (1) dan Perangkat Mastering (1).
- **Post-Production Studio:**
  - ✨ **Correction / Perfection:** Menyempurnakan kejernihan, dinamika, dan transisi melodi.
  - ✂️ **Remove + Generate:** Menghapus stem tertentu (Vokal / Gitar / Bass / Drum) dan mengisinya ulang dengan AI.
  - 🎙️ **Remake + Record + Generate:** Rekam suara/instrumen langsung dari mikrofon HP Anda dan ubah menjadi aransemen studio.
- **Open-Source API Ready:** Terhubung secara default ke endpoint gratis/open-source **ACE-Step** (Hugging Face / Colab / Custom Local Server) yang bisa Anda ubah kapan saja di menu pengaturan.

## 🚀 Cara Menjalankan (100% dari HP / GitHub)
1. Upload 4 file (`README.md`, `index.html`, `catalog.js`, `app.js`) ke repositori GitHub baru Anda.
2. Masuk ke **Settings > Pages** pada repositori GitHub Anda.
3. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
4. Aplikasi web siap dibuka di browser HP Anda dan dapat di-install ke layar utama (*Add to Home Screen*) atau dibungkus menjadi APK Android menggunakan **WebIntoApp / Capacitor / Android Studio WebView**.
